# Security

If you find a security problem with this repository (for example an exposed credential, or
content that should not be public), please **do not post the details publicly**.

Open an issue titled **"Security contact request"** that contains no technical details. The
maintainer, [@LockingFR](https://github.com/LockingFR), will reply with a private way to send
the report.

This repository does not ship binaries, accept uploads of game data, or run automated
workflows with access to other repositories.
