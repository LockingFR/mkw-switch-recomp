# Security

If you find a security problem with this repository (for example an exposed credential, or
content that should not be public), please **do not open a public issue**. Report it privately
through GitHub's **"Report a vulnerability"** button in this repository's *Security* tab; the
report is visible only to the maintainer, [@LockingFR](https://github.com/LockingFR).

This repository does not ship binaries, accept uploads of game data, or run automated
workflows with access to other repositories.
