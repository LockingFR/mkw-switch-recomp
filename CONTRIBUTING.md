# Contributing

Thank you for your interest in MKW Switch, created and led by
[@LockingFR](https://github.com/LockingFR).

## Before you start

1. **Contact LockingFR first** — open an issue titled "Contribution proposal: …" — to agree on
   the scope of any significant contribution.
   Most of the runtime lives in a private repository; many changes cannot be reviewed here.
2. Read [STATUS](docs/STATUS.md) and the [roadmap](docs/ROADMAP.md). Current priorities are race
   performance at correct game speed, then gameplay completeness and stability, then audio.

## Hard rules

- **Never submit** game files, disc images, extracted assets, NAND dumps, keys, Nintendo SDK
  code or headers, translated/generated game code, complete builds, or logs/captures that
  contain game data. Such submissions are deleted without review.
- Only submit work you have the right to submit. Do not paste code from other projects unless
  its license allows it and you say where it comes from.
- Do not claim performance gains without comparable hardware measurements; PC or emulator tests
  are not Switch validation.

## Rights

Contributions remain attributed to their authors. Because no general open-source license is
granted for this repository (see [LEGAL.md](LEGAL.md)), the terms under which a contribution is
integrated are agreed with the project lead before it is merged. Opening a proposal does not
imply it will be accepted.

## Reporting a problem

Open an issue describing the problem, the build or commit concerned, and how to reproduce it.
Do not attach game data. For security-sensitive reports, see [SECURITY.md](SECURITY.md).
